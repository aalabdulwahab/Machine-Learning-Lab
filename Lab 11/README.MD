This assignment Lab 11 applies K-Means clustering to segment credit card customers based on their financial behavior and spending patterns.

- Loaded and explored the dataset
- Handled missing values using mean imputation
- Removed unnecessary columns such as `CUST_ID`
- Scaled features using `StandardScaler`
- Applied K-Means clustering
- Used the Elbow Method and Silhouette Score to determine the optimal number of clusters
- Visualized customer segments
- Analyzed and interpreted each cluster


The optimal number of clusters was K = 4, representing:
1. Inactive Customers
2. Cash Advance Users
3. Active Shoppers
4. Premium Customers

Customer segmentation helps identify different customer behaviors and supports targeted marketing strategies, personalized services, and better business decision-making.
